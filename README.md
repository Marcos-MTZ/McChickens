# McChickens
Repositorio de la API McChickens

## Requisitos para ejecutar el proyecto

- JDK compatible con el proyecto.
- Apache NetBeans 25.
- Apache Tomcat 10.0.5.
- MySQL Server y una base de datos configurada para la API.

## Configuración

1. Clonar el repositorio.
2. Instalar Apache Tomcat 10.0.5 y registrarlo en NetBeans.
3. Configurar las credenciales de administración de Tomcat según los requisitos del IDE.
4. Configurar la conexión a la base de datos MySQL `mcchickens`.
5. Abrir el proyecto `mcchickens_Rest` en NetBeans.
6. Verificar las dependencias de los proyectos `mcchickens_core` y `mcsChickens_model`.
7. Compilar y ejecutar la API REST desde NetBeans.

**Nota:** las rutas de instalación de Tomcat y la configuración de Catalina Base son locales y deben ajustarse al entorno de cada usuario.
